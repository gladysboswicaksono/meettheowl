The three-block structure

When AI generates an interactive course or reference guide, it almost always produces a single file. Everything lives inside one .html file: the content, the styling, and the interactivity. Most AI-generated courses follow the same predictable structure — once you see it, you'll recognise it everywhere.

Block 1
HTML — the content

Text, headings, and the skeleton of any interactions. This is what you edit when you want to change words, headings, or the order of things.

<body> … </body>
Block 2
CSS — the appearance

Colors, spacing, fonts, layout. Lives in a <style> tag in the <head>. This is what you edit when something looks wrong.

<style> … </style>
Block 3
JavaScript — the behaviour

Two layers: a data layer (the content stored as objects) and a behaviour layer (what happens when the user clicks). Edit the data layer to change step titles and body copy.

<script> … </script>
See it in the file

Here's how those three blocks look inside stepper.html. Notice how each block is marked with a comment so you know exactly where you are.

<!-- ═══ HTML Structure ═══════════════════════ --> <body> <div class="page-content"> <h3 class="page-heading">Tips to work with AI</h3> <p class="page-body">The output quality depends…</p> </div> <!-- stepper markup below --> </body>
<!-- ═══ Style block (CSS) ════════════════════ --> <style> .page-heading { font-family: 'Cinzel', serif; font-size: 20px; color: #2A2A2A; } .stepper__step.is-active { background: #5B0606; /* ← this is the red color */ color: #FAFAF8; } </style>
<!-- ═══ JavaScript ══════════════════════════ --> <script> // DATA LAYER — edit this to change step content const steps = [ { title: 'Point it to your design system', body: 'Have a file with your themes…' }, // … more steps ]; // BEHAVIOUR LAYER — handles clicks and rendering function setStep(i) { active = i; render(); } function go(dir) { active = Math.max(0, …); render(); } </script>
The rule

Change text and structure? Look in the HTML block.
Change how it looks? Look in the <style> block.
Change what's in an interaction? Look for the data array in the <script> block.

That's it. The rest of this course is practice.

Lesson 3

What to remember

Three patterns you can apply to any AI-generated file — not just steppers.

The three questions
  1. What needs to change — text, look, or behaviour?
    That tells you which block to open: HTML, CSS, or JS.
  2. Is the content hardcoded in HTML, or generated from a JS array?
    If it's JS-generated, editing the HTML directly won't stick. Find the data array and edit it there.
  3. Which class name controls this element?
    Right-click → Inspect in your browser. The class in the Elements panel is the same one in the CSS block. Find it, edit it.
When you're prompting AI to generate a file

Ask it to use a comment above every major section. This takes 10 seconds to add to your prompt and saves you from hunting through 200 lines to find the right block.

/* ── Navigation controls ── */ .stepper__controls { … } /* ── Detail panel ── */ .stepper__detail { … }

Also ask for readable class names. .step-detail and .accordion-body tell you what they are. .c1 and .x2 don't.
